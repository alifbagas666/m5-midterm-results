# Data

The M5 data is not included. Download it from Kaggle (competition `m5-forecasting-accuracy`):
`calendar.csv`, `sales_train_evaluation.csv`, `sell_prices.csv`, and the evaluation-period sales
(days d_1942 to d_1969) released by the organisers, so that the sales file holds 1,969 days.
Put the files in one folder and pass it as `--data_dir`.
